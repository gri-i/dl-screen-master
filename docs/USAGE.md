# Руководство пользователя DL_SCREEN MASTER

Это руководство описывает рабочий процесс в приложении: от базы кабинетов
до готового PDF-отчёта по проекту.

## 1. База кабинетов

Перед началом работы в базе должна быть хотя бы одна модель LED-кабинета.
Откройте **Настройки** (кнопка в правом верхнем углу):

- **Импорт RCFG / RCFGX** — добавляет один кабинет из файла конфигурации
  NovaStar (разрешение и шаг пикселя определяются автоматически).
- **Импорт JSON** / **Экспорт JSON** — перенос всей библиотеки кабинетов
  между установками.
- **Добавить кабинет** — ручной ввод бренда, модели, шага пикселя,
  разрешения, габаритов, веса и мощности (макс./средней).

Каждую модель можно отредактировать или удалить прямо в списке
библиотеки. Изменения сразу доступны в основном окне.

В этом же разделе настроек задаются:

- **Оформление** — одна из 8 цветовых тем (применяется мгновенно,
  сохраняется между запусками).
- **Электросеть** — напряжение, фаза, cos φ и номинал автомата по
  умолчанию для новых расчётов питания.

## 2. Пиксельная маска

Раздел **«Пиксельная маска»** — основной редактор раскладки экрана.

1. В левой панели выберите **модель кабинета** и задайте раскладку
   (кабинетов по горизонтали/вертикали). Панель расчёта сразу показывает
   разрешение, габариты, вес и ориентировочное число силовых цепей.
2. Нажмите **«Добавить экран на холст»** — экран появится на рабочей
   области уже с выбранным паттерном.
3. На холсте экраны можно перетаскивать (с примагничиванием краёв при
   стыковке), выделять рамкой или с Ctrl/Cmd, поворачивать на 90°
   (кнопка **↻ 90°**), масштабировать колесом мыши и панорамировать.
   Правый клик по кабинету удаляет его из раскладки, повторный правый
   клик по пустой ячейке возвращает кабинет обратно — это удобно для
   нестандартных по форме экранов (буквы, фигурные конструкции).
4. В правой панели настраиваются **паттерн** (шахматка, полосы,
   градиент, сетка, заливка, цветовая схема), **подпись экрана**
   (название, размер, цвет), **логотип** (позиция, ширина,
   непрозрачность) и **наложения** (границы кабинетов, нумерация,
   тестовая сетка, разрешение).
5. Отмена/повтор действий — **↶ / ↷** (Ctrl/Cmd+Z, Ctrl/Cmd+Y).

Все параметры масок хранятся внутри проекта и используются и в
«Пиксельной маске», и в «Расключении» — геометрия экранов общая.

## 3. Импорт NovaStar

Кнопка **«Импорт .srcx/.scr»** на панели инструментов «Пиксельной
маски»/«Расключения» разбирает файл сцены NovaStar целиком:

- кабинеты каждого экрана сопоставляются с уже существующими в базе
  пресетами — сначала по совпадению **бренд + модель**, затем, если
  совпадения нет, по **пиксельному разрешению** (только если в базе
  ровно один пресет с таким разрешением). Повторный импорт того же
  кабинета не создаёт дубликат пресета;
- если паспортные вес/мощность в файле отсутствуют (частый случай для
  `.srcx`/`.scr`), для нового пресета донором веса и мощности служит
  кабинет, выбранный в левой панели — геометрия (мм/px) при этом всегда
  берётся из самого файла;
- сигнальные пути (контроллер, физические выходы, порядок кабинетов в
  цепочке) восстанавливаются автоматически и сразу видны в разделе
  «Расключение».

Статус импорта (сколько экранов, сколько сопоставлено с базой, сколько
создано новых пресетов) отображается под кнопкой импорта.

## 4. Расключение: сигнальные пути

Переключитесь на раздел **«Расключение»**, выберите экран на холсте и
откройте вкладку **«Сигнал»** в правой панели.

### Автоматическая схема

В блоке **«Автоматическая схема»** выберите рисунок обхода (змейка по
строкам/колонкам, по строкам, по колонкам, от центра) и начальный угол.
Генератор обходит пустые ячейки и делит кабинеты между портами с учётом
их пиксельной ёмкости; если портов не хватает — выводится
предупреждение. Перед применением доступен графический предпросмотр
(цвет = порт), после — схему можно донастроить вручную.

### Ручное редактирование

Если на экране ещё нет контроллера — выберите модель NovaStar
(MCTRL4K, MCTRL660, MCTRL660 Pro, H9, H15) и, для H9/H15, число
установленных sending-карт, затем нажмите **«Добавить и редактировать
пути»**.

Когда контроллер уже есть, доступны:

- **«Редактировать трассы»** — выберите порт в списке, затем кликайте
  по кабинетам на холсте в порядке прохождения сигнала; повторный клик
  убирает кабинет из цепочки. Загрузка порта (% от лимита по пикселям
  или по числу кабинетов) видна прямо на кнопке порта, перегрузка
  подсвечивается.
- **«Сменить контроллер»** — открывает форму выбора другой модели
  (с тем же числом sending-карт по умолчанию) и **пересоздаёт все
  порты**: уже назначенные трассы на экране будут сброшены — это
  предупреждение показано прямо в форме.
- **«Добавить контроллер»** — для случая, когда портов текущего
  контроллера не хватает. Выберите вторую модель (или ту же) — её порты
  **добавятся к уже существующим**, без сброса ранее назначенных трасс.
  Новые sending-карты нумеруются начиная со следующего свободного
  номера, поэтому несколько контроллеров/карт на одном экране не
  конфликтуют друг с другом. Заголовок панели показывает сводку по всем
  контроллерам экрана (например, `NovaStar · MCTRL4K + H9 ×2`).

Кнопки **«Очистить порт»** и **«Очистить все пути»** сбрасывают
назначения без удаления самого контроллера.

## 5. Расключение: силовые цепи

На той же панели переключитесь на вкладку **«Питание»**.

### Автоматическая схема

Используйте блок **«Автоматическая схема»** сверху панели: он строит и
сигнальные, и силовые цепи сразу, с предпросмотром и лимитом кабинетов
на линию. Это самый быстрый способ получить рабочую схему.

### Ручная донастройка

В самом блоке **Power path planning**:

- выберите **кабинет для расчёта питания** (мощность берётся из его
  пресета) и настройте напряжение, номинал автомата, запас и число фаз;
- **«+ Цепь»** добавляет одну пустую цепь, фаза подставляется по
  кругу (L1 → L2 → L3) для трёхфазной сети;
- **«+ Коробка 32А/3ф (6×16А)»** одним нажатием создаёт **6 цепей**,
  по 2 на каждую фазу — типовая раскладка силовой коробки с вводом 3ф
  32А и шестью розетками 16А на выходе. Действие переключает план на
  3 фазы и автомат 16А (номинал отходящей линии, а не ввода коробки);
- **«Рисовать силовые пути»** включает режим расстановки: выберите
  цепь в списке, затем кликайте по кабинетам на холсте. Карточка цепи
  показывает загрузку в % и в кВт, расчётный ток и перегрузку, если
  она есть;
- **«Очистить»** сбрасывает назначения во всех цепях, не удаляя их.

Суммарная строка под списком цепей показывает, сколько кабинетов из
общего числа назначено и сколько цепей перегружено.

## 6. Проекционные паттерны

Раздел **«Проекционные маски»** — генератор юстировочных паттернов для
мультипроекторных инсталляций, отдельно от раскладки LED-экранов.

- **Pixel Pattern** — сетка, окружности и зона перекрытия строятся по
  пиксельной сетке дисплеев (разрешение проектора, overlap X/Y, число
  проекторов по горизонтали/вертикали). Доступны три плотности сетки
  (Wide/Medium/Fine), толщина линий и цвета фона/сетки.
- **Metric Pattern** — тот же паттерн в метрической системе координат.
- Логотип можно наложить так же, как и в пиксельной маске (позиция,
  ширина, непрозрачность).
- Итоговый паттерн масштабируется колесом/кнопками **−/+**, экспорт —
  **«Скачать PNG»** или **«Экспорт PDF»** (PDF включает таблицу
  проекторов: позиция, разрешение, перекрытие).

## 7. Калькулятор

Раздел **«Калькулятор»** объединяет два независимых инструмента:

- **Параметры экрана** — та же раскладка, что и в «Пиксельной маске»:
  общее число кабинетов, разрешение, габариты, вес, пиковое/среднее
  потребление и рекомендуемое число силовых цепей.
- **Bandwidth Calculator** — пропускная способность HDMI 1.4b–2.2 и
  DisplayPort 1.1–2.1 (HBR/HBR2/HBR3/UHBR10/UHBR13.5/UHBR20) для
  выбранного разрешения и частоты, с учётом глубины цвета 8/10/12 бит,
  цветового формата (RGB/YCbCr 4:4:4/4:2:2/4:2:0), blanking и DSC
  2:1–3:1. Разрешение можно взять из параметров экрана или ввести
  вручную; калькулятор подсвечивает минимально подходящий режим HDMI/DP
  и предупреждает о превышении пропускной способности.

## 8. Экспорт

На панели инструментов «Пиксельной маски»/«Расключения»:

- **«PNG маска»** — сохраняет маску выбранного экрана; если выделено
  несколько экранов, сохраняется папка с общей маской (по фактическому
  положению и повороту экранов на холсте) и маской каждого экрана
  отдельно.
- **«PNG с путями»** — то же, но с наложенной схемой сигнального пути
  (доступно, если на экране настроен контроллер).
- **«Экспорт PDF»** — PDF-отчёт по проекту: сводная таблица экранов и,
  для каждого экрана, страницы с маской, схемой сигнальных путей и
  схемой силовых цепей (с таблицами портов/цепей и статусом
  перегрузки). PNG-файлы масок сохраняются рядом с отчётом в отдельной
  папке, названной по имени проекта.

## 9. Настройки и проекты

- **«Новый»** — очищает текущую раскладку и начинает новый проект.
- **«Открыть»** / **«Сохранить»** — работа с файлами проекта `.dlscreen`
  (JSON) через системный диалог выбора файла; библиотека кабинетов в
  проект не входит и хранится отдельно (профиль приложения).
- **«Очистить все»** — убирает все экраны с текущей рабочей области.

Подробности о том, что именно хранится в файле проекта и как устроена
модель данных — в `src/shared/types.ts`.
