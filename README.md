# DL_SCREEN MASTER

**Русский** · [English](README.en.md)

Desktop-приложение (Electron + React + TypeScript) для проектирования
LED-экранов: раскладка кабинетов, пиксельные маски, сигнальные и силовые
схемы подключения, проекционные паттерны для мультипроекторных инсталляций
и инженерные калькуляторы.

![Пиксельная маска](docs/screenshots/pixel-mask.png)

## Возможности

- **Пиксельная маска** — раскладка экрана из кабинетов с реальным
  разрешением, паттерны (шахматка, полосы, градиент, сетка, заливка),
  несколько экранов на одной рабочей области с перетаскиванием,
  примагничиванием краёв, поворотом и выравниванием. Подпись экрана,
  логотип, выбор цветов и границ кабинетов.
- **Расключение (Wiring)** — ручное и автоматическое построение
  сигнальных (data path) и силовых (power path) схем:
  - автогенератор маршрутов змейкой, по строкам/колонкам или от центра,
    с выбором стартового угла и графическим предпросмотром перед
    применением;
  - контроль ёмкости портов (пиксели/кабинеты на порт) и перегрузки
    силовых цепей с распределением по фазам L1/L2/L3;
  - добавление контроллера NovaStar (MCTRL4K/660/660 Pro, H9, H15),
    смена контроллера и **добавление ещё одного контроллера**, когда
    портов текущего не хватает — уже назначенные трассы сохраняются;
  - быстрое добавление силовой коробки **3ф 32А → 6×16А** одним
    нажатием, с распределением цепей по фазам.
- **Импорт NovaStar** — `.srcx`/`.scr` (сцена целиком, с автоматическим
  сопоставлением кабинетов с базой пресетов; multi-card записи сохраняют
  смещения sender, физические порты и порядок кабинетов) и `.rcfg`/`.rcfgx`
  (отдельный кабинет).
- **Проекционные паттерны** — генератор Pixel Pattern (сетка, окружности,
  перекрытие) и Metric Pattern для юстировки мультипроекторных
  инсталляций, с сеткой дисплеев, overlap и экспортом в PNG/PDF.
- **Калькулятор** — вес, габариты, потребление и рекомендуемое число
  силовых цепей экрана; Bandwidth Calculator для HDMI 1.4b–2.2 и
  DisplayPort 1.1–2.1 (RGB/YCbCr, глубина цвета, blanking, DSC).
- **Аппаратные лимиты** — официально подтверждённые ограничения портов и
  контроллеров учитывают битность; для неизвестных вариантов приложение
  показывает `unknown`, а не подставляет догадку.
- **Экспорт** — PNG-маска (объединённая и по отдельности для нескольких
  выделенных экранов), PNG со схемой сигнального пути, PDF-отчёт по
  проекту со сводной таблицей, масками и схемами подключения, CSV-ведомость
  кабинетов и XML-заготовка Advanced Output для Resolume.
- **CSV-ведомость** — один UTF-8 CSV с BOM и разделителем `;`: по строке на
  кабинет, с координатами, моделью, портом и порядком в цепочке; подключённые
  кабинеты идут в порядке портов, неподключённые — в конце.
- **Resolume XML** — заготовка Advanced Output с Screen на экран и Slice на
  порт. Нужны назначенные сигнальные пути; физические выходы назначаются в
  Resolume вручную, а для повёрнутых экранов поворот также задаётся вручную.
  Живой импорт в Arena не проверен, формат может отличаться между версиями.
- **Проекты `.dlscreen`** — сохранение и открытие через Electron IPC;
  снимок проекта содержит только пользовательские пресеты, на которые
  ссылаются его экраны; глобальная библиотека сохраняется и объединяется
  при открытии, а несовместимые конфликты `id`/«бренд + модель» сообщаются.
  Сохранение атомарное, переходы с несохранёнными изменениями защищены,
  предусмотрено восстановление после сбоя.
- **Два языка интерфейса** — русский и английский, переключается в
  настройках и сохраняется между запусками.
- **Темы оформления** — 8 цветовых тем DreamLaser Design System,
  применяются мгновенно и сохраняются между запусками.

## Установка и запуск

```bash
npm install
npm run dev      # запуск в режиме разработки
```

```bash
npm run build     # production-сборка renderer/main
npm run package   # сборка установщиков (electron-builder), результат в release/
```

Проверки проекта для разработки и CI:

```bash
npm test              # vitest run
npm run typecheck     # tsc --noEmit
npm run build         # production-сборка
```

Реальный GUI smoke test Electron и UI-пути IPC отдельно не выполнялись; эта
документация не объявляет их проверенными.

`npm run package` локально собирает установщики в `release/` для Windows x64 и
macOS x64/arm64. Эта команда не означает, что текущая ветка или `main` уже
является выпущенным установщиком. Версия 0.2.0 соответствует тегу `v0.2.0`
([e8451a6](https://github.com/gri-i/dl-screen-master/commit/e8451a6)); более
поздние изменения относятся к `Unreleased`.

Сборки для macOS не подписаны (`identity: null`): при первом запуске откройте
приложение через правый клик → «Открыть».

## Структура проекта

```
src/
  main/            — Electron main process (окно, IPC, файловые диалоги)
  renderer/        — React UI
    components/    — редактор масок, расключение, калькуляторы
    sections/      — проекционные паттерны
    i18n/          — переводы интерфейса (ru/en) и языковой контекст
  shared/          — общий код: типы данных и бизнес-логика расчётов
                     (не зависит ни от Electron, ни от React)
docs/
  screenshots/      — изображения для README
  USAGE.md          — руководство пользователя (русский)
  USAGE.en.md       — руководство пользователя (English)
```
