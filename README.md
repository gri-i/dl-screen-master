# DL_SCREEN MASTER

Минимальный рабочий скелет desktop-приложения (Electron + React + TypeScript)
для проектирования LED-экранов: раскладка, вес, питание, data path.

## Что уже работает

- Модель данных: `CabinetPreset`, `Screen`, `Processor`, `PowerGridConfig`
  (см. `src/shared/types.ts`)
- Логика расчёта веса/габаритов/потребления и рекомендуемого числа
  цепей питания (см. `src/shared/calculations.ts`)
- Простой UI-калькулятор (ввод кол-ва кабинетов по X/Y → вывод результата)
  с выбором модели кабинета и коэффициентом мощности нагрузки (см. `src/renderer/components/PowerCalculator.tsx`)
- Библиотека пресетов (`src/shared/presets.ts`) с двумя реальными моделями:
  - **Absen KL2.5** — 640×480×60 мм, 7.8 кг, макс. 360 Вт / сред. 120 Вт на кабинет
  - **Yestech MG7S P3.9** — 500×500×73 мм, 6 кг, макс. 187.5 Вт / сред. 70 Вт на кабинет
- Раздел **"Тестовые паттерны"** (`src/renderer/components/TestPatternViewer.tsx`) —
  канвас с реальным разрешением экрана, паттерны: шахматка, цветные полосы,
  градиент, сетка, заливка; наложение границ физических кабинетов;
  информационная панель (разрешение, физический размер, шаг пикселя).
  Правый клик по кабинету удаляет его из раскладки, правый клик по пустой ячейке добавляет обратно;
  калькулятор питания учитывает только установленные кабинеты.
  Логика генерации паттернов — в `src/shared/patterns.ts`, отдельно от React.
- Несколько экранов на рабочей области: добавление текущей маски на холст,
  перетаскивание и примагничивание краёв при стыковке.
- Оверлеи для маски: название и разрешение в центре, логотип, выбор цветов,
  белая обводка текста и экспорт PNG с прозрачными пустыми ячейками.
- Отдельное окно настроек: добавление и удаление пользовательских типов
  LED-кабинетов; новые типы сразу доступны в основном окне.

## Запуск

```bash
npm install
npm run dev
```

Откроется Electron-окно редактора экранов.

## Дорожная карта (следующие шаги)

1. **✅ Модель проекта и сохранение на диск** — добавлены полноценные
   сущности `Project`/`ScreenInstance` с моделями кабинетов, вырезами,
   позицией, паттерном и оверлеями. Команды «Новый», «Открыть», «Сохранить»
   работают через безопасный preload/IPC; формат проекта — JSON (`.dlscreen`).

2. **✅ Полноценный редактор рабочей области** — добавлены масштабирование
   колесом относительно курсора, панорамирование, рамка и Ctrl/Cmd-выделение,
   перемещение групп экранов, направляющие примагничивания, выравнивание,
   распределение и undo/redo (Ctrl/Cmd+Z, Ctrl/Cmd+Y).

3. **✅ Стыковка по физическим размерам** — координаты и стыковка используют
   физические габариты кабинетов; добавлен поворот с пересчётом размеров,
   защита от пересечений и отображение ближайшего расстояния/зазора в мм.

4. **✅ Библиотека пресетов** — пользовательские модели вынесены из
   `localStorage` в профильный JSON через preload/IPC (со встроенной миграцией).
   Добавлены импорт/экспорт JSON, проверка диапазонов и защита от дубликатов.

5. **✅ Импорт Data Path из NovaStar** — импорт `.srcx` восстанавливает
   контроллер, физические выходы и порядок кабинетов в каждой цепочке по
   полям `PortName` (контроллер), `Port` (физический выход) и `Connect`
   (порядок кабинета в цепочке). Цветные трассы со стрелками, начальной и
   конечной точками отображаются прямо поверх кабинетов. В режиме редактирования
   можно очистить порт или всю схему и заново построить путь последовательными
   кликами по кабинетам. Результат сохраняется внутри проекта `.dlscreen`.

6. **✅ Power path planning** — добавлено ручное назначение кабинетов силовым
   цепям, настройка напряжения, автомата и запаса, контроль тока и перегрузки
   каждой цепи. Автобаланс создаёт необходимое число цепей и распределяет их
   между L1/L2/L3; силовой план сохраняется внутри проекта `.dlscreen`.

7. **✅ Экспорт проекта** — добавлен ZIP-пакет с CSV pick-листом, перечнем
   экранов, ведомостями питания и data-path для Excel/Google Sheets,
   SVG-схемами раскладки со стрелками направления, PNG всех экранов,
   отдельными PNG-схемами data-path и объединёнными картами масок и
   расключения. PDF-отчёт проекта экспортируется отдельной командой.

8. **Мульти-пресетные экраны** — сейчас `calculateScreenPower`
   предполагает один пресет на весь экран. Если нужны смешанные
   раскладки (разные модели в одном экране), расширить
   `CabinetInstance`, добавив `presetId` на уровне инстанса (уже есть)
   и убрать зависимость расчёта от единого `preset`.

9. **Инженерные проверки** — подсветка некорректных чисел, недопустимых
   вырезов, превышения мощности, ошибок порта и конфликтов экранов;
   отдельная панель предупреждений перед экспортом.

10. **Тесты и поставка** — unit-тесты для расчётов/паттернов, e2e-проверки
   редактора, автосохранение и сборка подписанных установщиков для macOS
   и Windows.

11. **Разделы** — разделить функции приложения по категориям:
   - пиксельная маска;
   - расключение;
   - проекционные маски;
   - калькулятор.

12. **Автоматическая генерация схем подключения** — построение data-path:
   - схемы змейкой, по строкам, колонкам и от центра;
   - выбор начального угла и направления;
   - автоматическое разделение по портам;
   - контроль пикселей и количества кабинетов;
   - обход пустых ячеек;
   - автоматические силовые зоны;
   - балансировка L1/L2/L3;
   - предварительный просмотр;
   - ручная корректировка после генерации.

## Структура проекта

```
src/
  main/           — Electron main process (окно, жизненный цикл)
  renderer/        — React UI
    components/
  shared/          — общий код: типы данных и бизнес-логика расчётов
                     (не зависит ни от Electron, ни от React —
                     можно переиспользовать в тестах или в будущем
                     мобильном/веб-клиенте)
```
